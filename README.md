# ReminderGym

A simple Android app I made to keep track of my gym reminders and workouts. Everything stays on your phone, with no account and no internet needed.

## Features

- **Reminders:** set a time, pick the days it repeats, and get a notification even when the app is closed
- **Gym log:** log exercise, sets, reps, weight and RIR, with suggestions as you type
- **Progress:** a line chart of your best weight per exercise and a calendar of the days you trained
- Light and dark theme

## Known issues

- Updates might erase saved data because no proper backend is added
- Reminders stop after a phone restart
- Some phones block alarms to save battery. Set the app's battery to "Unrestricted" if reminders don't fire

## Why I made it

I'm learning Android development, and this is my first real app.
